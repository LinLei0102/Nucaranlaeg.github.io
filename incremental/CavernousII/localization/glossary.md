# 术语表（唯一权威）

## 绝对不译

- 品牌与人名：`Nucaranlaeg`、`PayPal`、`Discord`、`Cavernous III`
- 按键名：`WASD`、`Ctrl`、`Shift`、`Tab`、`Home/End`、`Backspace`、`W/A/S/D/Q/Z/L/G/S/P/R/F/B` 等单个键位
- 代码与数据：内部 id、class、资源路径、`location_types` 的符号字符（`█ ♣ ╬ ⎶` 等）
- 大数记号：`e10`、`∞`（Infinity）

## 标点与排版

- 译文使用全角冒号「：」，避免被 `^xxx: yyy$` 这类宽泛模板二次翻译。
- 并列项用顿号「、」，**不要用半角连字符**，否则会被 id 掩码逻辑误伤。
- 数字与中文单位之间留一个半角空格（`5 块铁锭`）。
- 句末用中文句号「。」；原文 `!` 保留为「！」。
